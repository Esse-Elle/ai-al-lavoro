Chapter six: skills, agents and the other tools that power up Claude. Let's start with skills. A skill is a folder with an instruction file that teaches Claude how to do a task well: a method, a tone, a format. The metaphor is a manual on the shelf: Claude picks it up when it's needed. It switches on by itself when the request matches, or you call it up yourself with the slash. And it works in every project.

What's inside? No code required: it's text. At the top there's a name and a description, and it's the description that decides when the skill kicks in. For example: "use this skill when you write copy, posts, press releases or newsletters for the brand". Below that is the method: the tone of voice, words to use and words to avoid, approved examples. If a skill doesn't kick in when it should, the culprit is almost always a description that's too vague.

Where do you find skills? In Claude's marketplace, which brings together plugins, connectors, agents and partners in one place. You get there from Customize. You'll find ready-made skills for Word, Excel, PowerPoint and PDF, plugins that bundle several skills together, like the Marketing and Brand Voice plugins, and the skills your team shares with everyone.

But the real value comes when you create a custom skill. Pick a task you repeat often, always the same way. Ask Claude: "create a skill that…", and describe the task. Claude asks you a few questions, then writes the skill. Attach good examples and bad examples: they make it precise. Save it, try it on three real cases, ask Claude to fix it, and then share it with the team.

A few ideas for marketing. A tone of voice skill, which rewrites any text in the brand's style. One for press releases, with structure, length and boilerplate. One for product sheets, turning technical data into emotional copy. One for social posts, with formats, lengths and hashtags for each channel. One for campaign reports, from the exports to the document for management. One for presentations in the group template. And one for briefs to agencies and photographers. If you had to pick just one to start with, it would be tone of voice.

Let's move on to agents. An agent is a collaborator with its own desk: Claude hands it a whole task, it carries it out on its own, in a separate context, and reports back only the result. It's useful for long, multi-step jobs, for running several analyses in parallel, for broad research to be summarised, and for keeping the main conversation clean.

An agent is a role file with four elements: name and description, meaning who it is and when to use it; the tools it can use, like files, web and connectors; the model it works with; and the instructions, meaning its method. You create one by asking Claude, inside a plugin or in Claude Code. And if you want a simple way to start, a project with role instructions is already a lightweight agent.

So, skill or agent? It's not a choice: they work together. The skill is the manual: it brings knowledge, method and format, and it works inside the conversation. The agent is the collaborator: a role you delegate a whole task to. Skills provide the method, agents do the work. To get started, my advice is simple: skills first, they're the most useful investment. Agents come later, for big or parallel jobs.
