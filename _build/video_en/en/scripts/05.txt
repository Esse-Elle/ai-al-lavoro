Chapter five: working well. Knowing the tool isn't enough: the real difference is how you set up the work. Let's start with the chat. Before you hit enter, three choices change the answer: the model with its effort, the tools you turn on, and the project you're in. And a few good habits: one chat per topic, attach the material instead of summarising it in words, ask for sources when Claude searches the web, and rename important chats so you can find them again.

Then projects. A project is a space with permanent instructions and materials: every conversation inside it starts already knowing who you are and how you work. It's your collaborator's memory: you set it up once and it always knows you. There are two kinds of project. The ones on claude.ai live in your account and can be shared with the team. The ones in the desktop app connect to folders on your computer, and have their own memory and their own scheduled tasks. And the two can be linked.

And here's the move that changes everything: connecting the project to a folder. Claude works on your desk, not on copies uploaded to the chat. There are four advantages. It reads documents without you having to upload them. It always sees the latest version: if you update the price list in the folder, next time Claude already uses the new one. It saves outputs there, so you don't have to look for them. And it saves you tokens and time.

How should you organise the folder? A simple structure, the same for everyone. A main folder, for example Marketing Claude. Inside it, a folder called zero zero Read me, with instructions, tone of voice and rules. One for the brand: brand book, logo, palette, fonts. One for products: catalogues, sheets, price lists. One for approved examples, the texts and posts to imitate. One for inputs: briefs, data exports, new material. One for outputs, where Claude saves its work. And an archive for old versions. This way Claude always knows where to find the rules, where to read the materials and where to save.

The ideal project is set up in seven steps. Create the folder with this structure. In the desktop app go to Projects, plus, and choose to use an existing folder. Give the project a name and description. Write the instructions. Link the team's project on claude.ai, if there is one. Turn on only the connectors and skills you need. And run a first test: "read zero zero Read me and tell me what you understood about the brand". It checks that Claude has understood the rules before it produces anything.

An example of project instructions: "You are the brand's marketing collaborator. Before every job, read the Read me and Brand folders. Only use data found in the folder: if something's missing, ask, don't make it up. Elegant, warm tone, short sentences, no superlatives. Always save your work in the Output folder, named with date, topic and version. Never overwrite a file: create a new version. At the end, tell me what you did and where you saved it."

Now a question everyone asks: artifact or file? They're two different things. An artifact is a result that lives inside Claude: you find it in the Artifacts section, you share it with a link, and you edit it in Claude's editor or by asking Claude. A file, instead, is a real document, a Word, a PowerPoint, an Excel, a PDF, saved in your folder, which you open with Office. Often you have both: an artifact can be exported to Word, PowerPoint or PDF, and a file can be published as an artifact. The four most useful artifacts are Docs, documents to write and comment on together. Slides, presentations to project or export. Design, meaning graphics, mockups and pages. And live pages, small apps like trackers, calculators or dashboards.

And now a golden rule, maybe the most important in the whole course, because it stops you losing work. When Claude edits a file, it rewrites it from scratch. So if you've touched up a document by hand and then ask Claude to regenerate it, your changes disappear. There are two ways around it. Option A: ask Claude to make the changes, for example "on slide four shorten the title, on slide seven add the price". It regenerates the file without losing anything. Option B: want to touch it up by hand? First duplicate the file and rename it, for example with your name and "version two". Work on the copy: Claude won't touch it.

Let's close the chapter with Claude Design. It launched in April as a separate app, and since September it lives inside Claude. From a brief it produces an editable layout, even using the brand's design system. In marketing we use it for landing page and newsletter mockups, social posts, posters for showroom events and presentations in our style. It doesn't replace the graphic designer: it speeds up the first versions. And for photos, there's still Leonardo.
